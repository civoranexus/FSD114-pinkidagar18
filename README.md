# EduVillage – Online Learning Platform

## Project ID
FSD114

## Internship Program

## Project Description
EduVillage is a full stack online learning platform designed to connect students and educators
through structured digital courses. The platform supports role-based access (Student, Teacher, Admin),
secure authentication, course management, progress tracking, and assessments.

## Core Features
- Role-based Authentication (Student / Teacher / Admin)
- Course Creation & Management
- Student Dashboard with Progress Tracking
- Assessments & Grading
- Admin Monitoring & Reports

## Tech Stack (Planned)
- Frontend: React.js
- Backend: Node.js (Express) / Python (Flask/Django)
- Database: MySQL / PostgreSQL
- Version Control: Git & GitHub
